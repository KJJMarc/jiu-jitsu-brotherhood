# Jiu Jitsu Brotherhood rebuild: Stage 3 content taxonomy and migration map

Approved 16 September 2026.

## Taxonomy principles

- Preserve Articles and Techniques as separate visitor-facing sections.
- Give every record one primary category.
- Use tags for secondary subjects, positions, systems, rulesets and instructors.
- Do not import Shopify's existing product-style tags.
- Preserve the original slug and publication date unless a specific editorial reason requires a change.
- Keep the unpublished Heel Hook Details record as a draft.
